# Project Statement

## Title
Student Academic Tracker

## Problem Statement
Keeping student details and subject marks organized manually can be time-consuming and may lead to errors when finding a student's record or calculating academic summaries. This project provides a simple console-based system to organize student information and marks.

## Scope
The project supports local student record management, subject-wise marks entry, individual summaries, and a basic class summary. It is intended as a small educational project and is not a replacement for an official college information system.

## Target Users
Students or instructors who need a simple local demonstration of academic record management.

## High-Level Features
1. Student management: add, view, update, and delete records.
2. Marks management: enter and update marks for subjects.
3. Reporting: calculate individual averages and a class average.
